CSS 动画速成

学会这 5 招，模板质感翻倍

一、transition — 让变化变平滑

transition 是最常用的动画手段。任何 CSS 属性变化时，它帮你自动补帧，而不是生硬地跳变。

1. hover 变色

hover 我
.box { transition: background 0.3s, border-color 0.3s; }
.box:hover { background: #38bdf8; border-color: #38bdf8; }

2. hover 放大

scale
.box { transition: transform 0.25s ease; }
.box:hover { transform: scale(1.15); }

3. hover 上浮 + 阴影（卡片常用）

浮
.card { transition: transform 0.3s ease, box-shadow 0.3s ease; }
.card:hover {
  transform: translateY(-6px);
  box-shadow: 0 12px 28px rgba(0,0,0,0.4);
}

4. 按钮实战

.btn { transition: background 0.2s, transform 0.15s, box-shadow 0.2s; }
.btn:hover  { transform: translateY(-2px); box-shadow: 0 6px 20px rgba(...,0.35); }
.btn:active { transform: translateY(0); }   /* 按下去回弹 */

⚡ 关键点：transition 写在元素本身上（不是 :hover 里）。这样鼠标进入和离开都有动画。

二、transform — 变形不占位

transform 改变元素的视觉位置/大小/角度，但不触发页面重排，性能极好。动画尽量用 transform。

hover 旋转
hover 倾斜
transform: translateY(-8px);   /* 上移 (最常用，做悬浮) */
transform: translateX(10px);   /* 右移 */
transform: scale(1.1);         /* 放大 10% */
transform: rotate(5deg);       /* 旋转 5° */
transform: skewX(-5deg);       /* 水平倾斜 */

/* 组合使用 */
transform: translateY(-6px) scale(1.05);

⚡ 和 transition 搭配：transition: transform 0.3s → hover 时 transform 变化，自动过渡。

三、@keyframes — 关键帧动画

transition 只能做"A → B"的简单过渡。@keyframes 可以做循环、多阶段、复杂路径的动画。

1. 脉冲圆点（加载指示器常用）

@keyframes pulse {
  0%, 100% { opacity: 0.3; transform: scale(0.8); }
  50%      { opacity: 1;   transform: scale(1.3); }
}
.dot { animation: pulse 1.6s ease-in-out infinite; }

2. 弹跳球

@keyframes bounce {
  from { transform: translateY(0); }
  to   { transform: translateY(-30px); }
}
.ball { animation: bounce 0.8s ease infinite alternate; }

3. 骨架屏（加载占位）

.skeleton {
  background: linear-gradient(90deg, #1e293b 25%, #334155 50%, #1e293b 75%);
  background-size: 200% 100%;
  animation: shimmer 1.5s ease-in-out infinite;
}
@keyframes shimmer {
  0%   { background-position: 200% 0; }
  100% { background-position: -200% 0; }
}

animation 格式：名称 时长 缓动 延迟 次数 方向
常用：infinite（无限循环）、alternate（来回播放）、forwards（停在最后一帧）

四、滚动渐入 — 页面活了

元素进入视口时才出现，是最实用的模板技能。用 Intersection Observer（浏览器原生 API）实现。

卡片 2
每个卡片独立触发，无需写死延迟。
卡片 3
客户看到这种效果会觉得模板"很高级"。 
<!-- CSS -->
.reveal-card {
  opacity: 0;
  transform: translateY(30px);
  transition: opacity 0.6s ease, transform 0.6s ease;
}
.reveal-card.visible {
  opacity: 1;
  transform: translateY(0);
}

<!-- JS -->
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.classList.add('visible');
    }
  });
}, { threshold: 0.15 });

document.querySelectorAll('.reveal-card').forEach(el => observer.observe(el));

⚡ threshold: 0.15 表示元素露出 15% 时触发。调大则更晚触发。
