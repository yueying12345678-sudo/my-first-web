表单对接后端

让联系表单真正发消息给客户 —— 客单价翻倍的关键技能

一、表单是怎么提交的

<form action="https://example.com/submit" method="POST">
  <input name="email" type="email">       <!-- name 属性是后端收到的字段名 -->
  <input name="message" type="text">
  <button type="submit">发送</button>
</form>

点"发送"后，浏览器把表单数据打包发给 action 指定的 URL，然后页面跳转过去。

⚠️ GitHub Pages 只托管静态文件，不能运行后端代码。所以需要第三方表单服务来接收数据并转发邮件。

二、方案 A：Web3Forms（推荐，免费额度大）

每月 250 次免费提交，无需注册信用卡，上手最快。

步骤

1. 打开 web3forms.com，点 "Get Access Key"，输入邮箱

2. 收邮件拿到一个 access key（形如 xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx）

3. 把表单的 action 改成 Web3Forms 的地址，加一个隐藏字段放 key

代码

<form action="https://api.web3forms.com/submit" method="POST">
  <!-- 隐藏字段：你的 access key -->
  <input type="hidden" name="access_key" value="你的KEY">

  <!-- 你的表单字段 -->
  <input type="text" name="name" required>
  <input type="email" name="email" required>
  <textarea name="message" required></textarea>

  <button type="submit">发送</button>
</form>
✅ 优点：免费额度 250/月、支持自定义邮件模板、可设置跳转页面、无品牌水印
❌ 缺点：需要注册（免费）

三、方案 B：Formspree（老牌稳定）

每月 50 次免费提交，API 更简洁。

<form action="https://formspree.io/f/你的FORM_ID" method="POST">
  <input type="email" name="email">
  <textarea name="message"></textarea>
  <button type="submit">发送</button>
</form>

注册后在 Formspree 后台创建一个 Form，拿到 ID 替换到 action URL 即可。

✅ 优点：老牌服务、API 简单、文档全
❌ 缺点：免费仅 50 次/月，超出需付费

四、进阶：AJAX 无刷新提交

上面的方式提交后会跳转页面，体验不好。用 JavaScript 的 fetch API 可以做到无刷新提交，并在原页面显示结果。

演示

不会真发，仅模拟流程 
form.addEventListener('submit', async (e) => {
  e.preventDefault();  // 阻止默认跳转

  const formData = new FormData(form);  // 自动收集所有字段

  try {
    const res = await fetch('https://api.web3forms.com/submit', {
      method: 'POST',
      body: formData
    });

    if (res.ok) {
      // 成功 — 显示成功提示
      successBox.style.display = 'block';
      form.reset();
    } else {
      // 失败 — 显示错误提示
      throw new Error('提交失败');
    }
  } catch (err) {
    alert('发送失败，请稍后重试');
  }
});

⚡ 关键：e.preventDefault() 阻止页面跳转 → FormData 自动收集表单数据 → fetch 异步发送 → 根据返回结果显示成功/失败

五、怎么接到你的模板上

三个模板的表单结构都一样，改一处即可：

  1. 去 web3forms.com 拿一个 access key
  2. 找到模板的 <form>，加上 action 和隐藏字段
  3. 把 form.reset() 后的假成功提示改成真逻辑
模板当前状态改造后

簌甜同上同上
