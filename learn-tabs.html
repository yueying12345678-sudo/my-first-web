一、Tab 切换

常见于产品详情页、方案对比、价格表按年/月切换。

全球火箭发射计划、窗口期、载荷信息实时同步，覆盖 SpaceX、中国航天等主要发射服务商。
从上游稀有材料到下游卫星应用，可视化供应链关系，定位关键供应商与客户。
A 股及美股商业航天标的实时异动检测，主力资金流向追踪，自定义预警规则。 
<!-- HTML: 按钮 + 面板 -->
<button class="tab-btn active" data-tab="tab1">发射追踪</button>
<div class="tab-panel active" id="tab1">内容</div>

<!-- CSS: 激活状态 -->
.tab-panel { display: none; }
.tab-panel.active { display: block; }
.tab-btn.active { color: var(--accent); border-bottom-color: var(--accent); }

<!-- JS: 点击切换 -->
document.querySelectorAll('.tab-btn').forEach(btn => {
  btn.addEventListener('click', () => {
    // 移除所有 active
    document.querySelectorAll('.tab-btn, .tab-panel').forEach(el => el.classList.remove('active'));
    // 激活当前
    btn.classList.add('active');
    document.getElementById(btn.dataset.tab).classList.add('active');
  });
});

⚡ 关键：用 data-tab 属性关联按钮和面板，通过 btn.dataset.tab 读取。

<!-- CSS: max-height 过渡 -->
.acc-body {
  max-height: 0;
  overflow: hidden;
  transition: max-height 0.35s ease;
}
.acc-body.open { max-height: 200px; }  /* 值需要略大于实际内容高度 */

<!-- JS -->
header.addEventListener('click', () => {
  header.classList.toggle('open');
  const body = header.nextElementSibling;
  if (body.classList.contains('open')) {
    body.classList.remove('open');
    body.style.maxHeight = null;
  } else {
    body.classList.add('open');
    body.style.maxHeight = body.scrollHeight + 'px';  // 动态设置高度
  }
});

⚡ 关键：用 scrollHeight 动态获取内容高度，而不是写死数值。这样改文案不会错位。

<!-- 核心结构 -->
<div class="carousel-track" style="display:flex; transition:transform 0.4s;">
  <div class="carousel-slide">第1页</div>
  <div class="carousel-slide">第2页</div>
  <div class="carousel-slide">第3页</div>
</div>

<!-- JS: 通过 translateX 平移 -->
function goToSlide(index) {
  track.style.transform = 'translateX(-' + (index * 100) + '%)';
  currentIndex = index;
}

⚡ 关键：每个 slide 宽度 100%，切换就是 translateX(-100%)、translateX(-200%)...以此类推。配合 CSS transition 实现滑动效果。
