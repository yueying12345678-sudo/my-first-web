HTML / CSS / JavaScript 是什么

—— 前端开发的三个核心，一张图讲清楚

一、经典比喻

HTML

骨架

决定页面上有什么：标题、段落、按钮、输入框、图片

CSS

皮囊

决定页面长什么样：颜色、大小、间距、动画、布局

JavaScript

肌肉

决定页面能做什么：点击响应、数据处理、动态更新

三者各司其职。HTML 写内容，CSS 管样式，JS 管行为。改了数据只改 HTML，改了配色只改 CSS——这就是"关注点分离"。

二、HTML 标签

HTML 用尖括号标签组织内容。每个标签有开始和结束。

<h1>这是一级标题</h1>          <!-- h1~h6：标题，数字越小越大 -->
<p>这是一个段落。</p>
<button>点我</button>            <!-- 按钮 -->
<input type="text" placeholder="在这里输入...">   <!-- 输入框（自闭合标签） -->
<a href="https://example.com">链接文字</a>    <!-- 超链接 -->
<img src="图片地址" alt="描述">                <!-- 图片（自闭合） -->

自闭合标签（input、img、br、hr）不需要写 </标签名>。

三、CSS 样式

CSS 选择器找到元素，然后给属性赋值。

/* 选择器 { 属性: 值; } */
h1 {
  color: #38bdf8;           /* 文字颜色 */
  font-size: 32px;          /* 字号 */
}
.card {
  background: #1e293b;      /* 背景色 */
  border: 1px solid #334155;/* 边框：粗细 样式 颜色 */
  padding: 20px;            /* 内边距 */
  margin: 12px;             /* 外边距 */
  border-radius: 8px;       /* 圆角 */
}

四、JavaScript 交互

下面这个输入框是活的——打什么字，下面就显示什么。

// 拿到元素
var input = document.getElementById('demoInput');
var output = document.getElementById('output');

// 监听输入事件
input.addEventListener('input', function() {
  output.textContent = '你输入了：' + input.value;
});

// 监听点击事件
document.getElementById('clearBtn').addEventListener('click', function() {
  input.value = '';
  output.textContent = '';
});

三行要领：拿元素 → 绑事件 → 改内容。所有前端交互都是这个套路。
