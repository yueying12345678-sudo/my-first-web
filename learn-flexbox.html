Flexbox 弹性布局

一维布局神器——导航栏、卡片排列、居中对齐，全用它

一、主轴方向 flex-direction

决定元素排列方向：横着排还是竖着排。

A
B
C
.container {
  display: flex;
  flex-direction: row;          /* row | column | row-reverse | column-reverse */
}

二、主轴对齐 justify-content

元素在主轴上的分布方式。

1
2
3
.container {
  display: flex;
  justify-content: center;  /* 最常用：水平居中 */
  /* 其他：flex-start | flex-end | space-between | space-around | space-evenly */
}

space-between = 两端贴边，中间均分 | space-around = 每个元素左右有相同间距 | space-evenly = 所有间隙完全相等

三、交叉轴对齐 align-items

元素在交叉轴（垂直于主轴）上的对齐方式。最经典的用法：垂直居中。

短
高
中
.container {
  display: flex;
  align-items: center;       /* 垂直居中 — 这行值千金 */
  /* 其他：stretch | flex-start | flex-end */
}
完美居中只需两行：display:flex; align-items:center; justify-content:center; —— 告别 margin 负值和绝对定位的噩梦。

四、换行 flex-wrap

默认不换行（挤在一行）。设置 wrap 后，空间不够自动换到下一行。

.container {
  display: flex;
  flex-wrap: wrap;           /* nowrap | wrap */
  gap: 12px;                 /* 元素间距，比 margin 好用 */
}

五、实战：卡片网格

用 flex + wrap 做一个自适应的卡片列表——改变窗口宽度，卡片自动调整每行数量。

.card-grid {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}
.card {
  flex: 0 1 200px;          /* 不放大，可缩小，基础宽度 200px */
  /* 等价于：
     flex-grow: 0;          — 不占多余空间
     flex-shrink: 1;        — 空间不够时可以缩小
     flex-basis: 200px;     — 初始宽度 200px
  */
}

flex 三件套里最常用的是这个组合：元素宽度固定但数量自适应，比写死 grid-template-columns 灵活。
