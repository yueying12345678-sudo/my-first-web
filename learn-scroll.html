Intersection Observer —— 元素进入视口时触发动画

一、Intersection Observer 是什么

浏览器原生 API，监听元素何时进入/离开视口。不用监听 scroll 事件，性能更好。

var observer = new IntersectionObserver(function(entries) {
  entries.forEach(function(entry) {
    if (entry.isIntersecting) {
      entry.target.classList.add('visible');  // 进入视口 → 加动画类
    }
  });
}, {
  threshold: 0.2    // 元素 20% 可见时触发
});

// 观察所有 .reveal-card 元素
document.querySelectorAll('.reveal-card').forEach(function(el) {
  observer.observe(el);
});
不用再写 window.addEventListener('scroll', ...) 了。Observer 在浏览器底层运行，不阻塞主线程。

三、阅读进度条

页面顶部的蓝色进度条就是 scroll 驱动的。滚多远，进度条走多远。

window.addEventListener('scroll', function() {
  var scrollTop = window.scrollY;
  var docHeight = document.body.scrollHeight - window.innerHeight;
  var pct = (scrollTop / docHeight) * 100;
  progressBar.style.width = pct + '%';
});

进度条用 position:sticky;top:0; 固定在顶部，只跟滚动位置联动。

四、回到顶部按钮

右下角那个蓝色按钮——滚过一定距离后出现，点击平滑回到顶部。

window.addEventListener('scroll', function() {
  var show = window.scrollY > 500;
  backTopBtn.classList.toggle('show', show);
});

backTopBtn.addEventListener('click', function() {
  window.scrollTo({ top: 0, behavior: 'smooth' });
});

五、应用场景

懒加载图片图片滚到视口附近才开始加载，省流量
无限滚动滚到底部自动加载下一页（给底部放一个哨兵元素）
出场动画产品列表/时间线/图表，滚到才显示，逐条 animate
视频自动播放视频进入视口自动播放，离开自动暂停
数据曝光统计统计用户真正看到了哪些内容
