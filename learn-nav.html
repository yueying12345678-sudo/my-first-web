响应式导航栏

手机汉堡菜单 / 桌面横排导航 —— 最实用的 UI 组件

一、HTML 结构

Logo + 链接列表 + 汉堡按钮。按钮默认隐藏，手机端显示。

<nav class="navbar">
  <div class="logo">MySite</div>

  <ul class="nav-links">
    <li><a href="#">首页</a></li>
    <li><a href="#">产品</a></li>
    <li><a href="#">关于</a></li>
    <li><a href="#">联系</a></li>
  </ul>

  <button class="hamburger">&#9776;</button>  <!-- ☰ 三条横线图标 -->
</nav>

二、CSS：Flexbox + 媒体查询

桌面：flex 横排。手机：菜单隐藏 + 汉堡按钮显示。

.navbar {
  display: flex;
  align-items: center;
  justify-content: space-between;
  padding: 0 20px; height: 56px;
}
.nav-links {
  display: flex;             /* 桌面：横排 */
  gap: 4px; list-style: none;
}
.hamburger { display: none; } /* 桌面：隐藏按钮 */

/* ---- 手机端 ---- */
@media (max-width: 768px) {
  .nav-links   { display: none; }          /* 菜单收起 */
  .hamburger   { display: flex; }          /* 按钮出现 */
  .nav.open .nav-links {
    display: flex; flex-direction: column; /* 展开：竖排全宽 */
    position: absolute; top: 56px; left: 0; right: 0;
  }
}

三、JavaScript：点击切换

点汉堡按钮 → 加/删 open 类 → CSS 自动响应。

 hamburger.addEventListener('click', function() {
   nav.classList.toggle('open');
 });

 // 点菜单项后自动收起
 links.forEach(function(link) {
   link.addEventListener('click', function() {
     nav.classList.remove('open');
   });
 });

五、常见变体

固定顶部position:sticky;top:0; — 滚动时导航始终在顶部
下拉子菜单li 内部再嵌套 ul，hover 时 display:block
滚动变色监听 scroll 事件，滚动超过一定距离后加背景色
侧滑抽屉菜单从左侧滑入，用 translateX + transition
