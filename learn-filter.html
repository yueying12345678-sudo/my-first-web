一、文本搜索

输入关键词，实时过滤列表。

    没有匹配的产品
    searchInput.addEventListener('input', function() {
  var keyword = this.value.toLowerCase().trim();
  var found = 0;

  items.forEach(function(item) {
    var name = item.name.toLowerCase();
    var match = name.includes(keyword);   // 名字里包含关键词？
    item.el.classList.toggle('hidden', !match); // 不匹配就隐藏
    if (match) found++;
  });

  noResult.style.display = found === 0 ? 'block' : 'none';
});

    ⚡ 精髓：input 事件在每次输入时触发 → 拿到关键词 → 逐个比对 → toggle 显示/隐藏。includes 做模糊匹配，换成 indexOf 也行。

    二、分类筛选

    点击按钮按类型过滤，可以和搜索叠加使用。

      filterBtns.forEach(function(btn) {
  btn.addEventListener('click', function() {
    // 切换 active 样式
    filterBtns.forEach(function(b) { b.classList.remove('active'); });
    btn.classList.add('active');

    currentCat = btn.dataset.cat;
    filterAll(); // 同时应用搜索 + 分类
  });
});

function filterAll() {
  items.forEach(function(item) {
    var catOk = currentCat === 'all' || item.cat === currentCat;
    var searchOk = item.name.includes(keyword);
    item.el.classList.toggle('hidden', !(catOk && searchOk));
  });
}

      ⚡ 精髓：分类和搜索是两个独立条件，最终过滤 = 搜索OK && 分类OK。拆成两个变量，最后取交集。

      三、排序

      切换排序方式，价格从低到高、按名称、按分类。

      排序： 
        function sortAndRender() {
  var sorted = items.slice(); // 浅拷贝，不修改原数组

  if (sortBy === 'price-asc') {
    sorted.sort(function(a, b) { return a.price - b.price; });
  } else if (sortBy === 'price-desc') {
    sorted.sort(function(a, b) { return b.price - a.price; });
  } else if (sortBy === 'name') {
    sorted.sort(function(a, b) { return a.name.localeCompare(b.name, 'zh'); });
  }

  // 按新顺序重新插入 DOM
  var listEl = document.getElementById('sortList');
  listEl.innerHTML = '';
  sorted.forEach(function(item) { listEl.appendChild(item.el); });
}

        ⚡ Array.sort() 接受比较函数。数字用 a-b，字符串用 localeCompare（支持中文拼音排序）。

        四、万能三步骤

        所有过滤场景都是同一个模式：

        ① 存数据把数据放在 JS 数组里，每条包含 name / cat / price / el（DOM 引用）
        ② 算逻辑根据搜索词 / 分类 / 排序方式，过滤或重排数组
        ③ 渲结果toggle hidden 类（过滤）或调整 DOM 顺序（排序）

        这个模式放到 React/Vue 里也是一样的，只是 ② 变成了 state 更新，③ 由框架自动处理。
