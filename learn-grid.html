CSS Grid 网格布局

二维布局终极方案——页面骨架、仪表盘、相册，Grid 搞定

一、定义列数 grid-template-columns

用 fr（fraction，份数）来分配空间，比百分比直观。

.grid {
  display: grid;
  grid-template-columns: 200px 1fr 1fr;  /* 侧边栏 + 双栏内容 */
  /* repeat(3, 1fr) = 1fr 1fr 1fr       — 重复 3 次 */
}

二、跨列 / 跨行

让某个元素占多列或多行，像 Excel 的合并单元格。

.hero-card {
  grid-column: 1 / 3;       /* 从第 1 条线跨到第 3 条线 = 占 2 列 */
  grid-row: 1 / 3;          /* 占 2 行 */
}

Grid 的线编号从 1 开始，N 列就有 N+1 条线。简写：grid-column: span 2; 不写起始线，只写跨几列。

三、经典页面骨架

一套 Grid 写完整个页面布局：header / 侧栏 / 内容 / footer。

Header
Sidebar
Main Content
Footer
.page {
  display: grid;
  grid-template-columns: 200px 1fr;
  grid-template-rows: 60px 1fr 40px;
  min-height: 100vh;
}
.header  { grid-column: 1 / -1; }   /* -1 = 最后一根线 = 占满整行 */
.footer  { grid-column: 1 / -1; }
grid-column: 1 / -1 里的 -1 代表最后一根线。不管中间加了多少列，永远占满全行。

四、自适应列数 auto-fit

不用写媒体查询，自动算每行放几个。改变窗口宽度看看效果。

.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));
  gap: 16px;
}
/* 翻译：每列最小 150px，放不下了自动换行，多余空间均分 */

这一行替代了 Flexbox 里的 flex-wrap + 手动算宽度。响应式卡片列表的最佳实践。
